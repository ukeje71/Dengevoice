## Project Description
DengeVoice lets citizens report public-service problems by speaking naturally , mixing Igbo and English the way people actually talk instead of filling an English-only form. Speech is transcribed, translated, and structured into a complaint automatically, then routed with a trackable ID. Built for Intron's Sahara CodeSwitch Africa Challenge 2026 (Legal & Public Services track).
